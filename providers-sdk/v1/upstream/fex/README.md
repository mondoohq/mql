# fex: the Finding Exchange contract

`fex.proto` (package `mql.fex.v1`) is the public contract for finding and
vulnerability documents and for the findings upload file
(`FindingsUploadRequest`). Field numbers stay wire-compatible with the
platform's copy of these messages: fields 7, 8 and 10 to 12 of
`FindingsUploadRequest` are used by that copy and are not assigned here.

Code is generated by `go generate ./providers-sdk/v1/upstream/fex` (part of
`make shared/generate`). Never edit `fex.pb.go` or `fex_vtproto.pb.go` by hand.

## Completeness of a full pull

An upload with `import_started_at` set is a full pull: the platform closes, by
absence, the findings of the upload's `source` on the assets the upload covers.
Three fields narrow what a full pull is complete for, and all that are set
apply:

| Field | Narrows by |
|---|---|
| `complete_kinds` (9) | finding kind: `FINDING_KIND_FINDING`, `FINDING_KIND_VULNERABILITY` |
| `scanned_components` (13) | the assets covered, for a pull that found nothing |
| `reporter` (14) | the producer mode the upload speaks for |

An upload without `import_started_at` (a delta) closes nothing, whatever these
fields say.

## `reporter`

One producer can report two kinds of results under one source, for example a
code scanner with a code mode and a data-flow mode. Without `reporter`, a full
pull of one mode closes the findings the other mode reported. With it, the
platform closes by absence only the findings last reported under the same
reporter.

- Format: `<producer>:<mode>`, lower-case ASCII letters, digits and `-`, one `:`
  separating two non-empty parts, at most 64 bytes (`^[a-z0-9-]+:[a-z0-9-]+$`).
  `fex.ValidReporter` checks it.
- It is not free text. The platform accepts, per source, only the reporter
  values it knows, and refuses an upload with any other value. `ValidReporter`
  checks the format only, not whether a value is accepted.
- One reporter per upload. A producer with two modes sends two uploads.
- Optional. An empty `reporter` keeps the behaviour of a request without the
  field, so existing producers are unaffected.
